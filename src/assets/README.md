# Stryvexa Brand Assets

Este paquete fue creado a partir de la propuesta de logo seleccionada para Stryvexa.

## Colores
- Violeta: #7C3AED
- Azul eléctrico: #4F46E5
- Cian: #22D3EE
- Azul oscuro: #0F172A
- Blanco: #FFFFFF

## Carpetas
- `logos/`: logo principal, logo horizontal y símbolo.
- `icons/`: iconos generales de aplicación.
- `favicons/`: favicon PNG e ICO.
- `mobile/`: Apple Touch Icon, Android/adaptive foreground y splash.
- `web/`: iconos PWA.
- `source/`: imagen de referencia original y paleta.

## Recomendación de uso
- Flutter app launcher: `icons/stryvexa-app-icon-1024.png`
- Android adaptive foreground: `mobile/adaptive-icon-foreground-1024.png`
- Android adaptive background: usar color `#0F172A`
- Splash: `mobile/splash-symbol-transparent-1024.png`
- Web favicon: `favicons/favicon.ico`
- Apple: `mobile/apple-touch-icon-180.png`
- PWA: `web/pwa-icon-192.png` y `web/pwa-icon-512.png`

## Nota
Los archivos se derivan de una imagen rasterizada generada previamente. Para impresión de gran formato o un manual de marca definitivo conviene redibujar el símbolo en SVG/vector manteniendo exactamente esta geometría.
